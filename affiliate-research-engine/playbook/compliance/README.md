## 自動化したい場合（Hooks案・任意）

Claude Code の Hooks で「ドラフト保存時に自動でコンプラチェック」を走らせられる。
ただし**この github.io リポジトリ全体に強制すると、無関係なファイル保存でも走ってしまう**ため、
デフォルトでは有効化していない。記事運用を専用リポジトリで回すなら、その `.claude/settings.json` に:

```json
{
  "hooks": {
    "PostToolUse": [{
      "matcher": "Write|Edit",
      "hooks": [{
        "type": "command",
        "command": "jq -r '.tool_input.file_path' | grep -q '/drafts/.*\\.md$' && echo '⚠️ ドラフト保存: 公開前にテク36/37のコンプラチェックを通すこと' || true"
      }]
    }]
  }
}
```

これは「リマインダー型」（保存時に注意を出すだけ）。
LLMに実チェックさせる `type: prompt` / `type: agent` フックも作れるが、毎回コストがかかるので、
**公開直前にまとめて手動で2ゲートを通す運用を推奨**。
