# 運用マニュアル — 何がいつ動いて、どこを見ればいいか

自動で動くものと、あなたがやることの切り分け。迷ったらここを見る。

---

## 1. 全体の流れ（1週間の動き）

```
月 09:00  案件コレクター     → 新しいアフィ案件を探して候補リストに積む
月 06:00  記事ドラフター(3日ごと) → アフィ記事 + Threads投稿文 + Instagramキャプション
火
水 06:00  記事ドラフター
木
金 06:00  記事ドラフター
土 06:00  Threads単発生成（予備。記事と別軸でネタが欲しい時）
日
毎日数回  X自動投稿         → 全自動。何もしなくていい
```

---

## 2. どこに何が出るか

## 4. 毎回やること（記事が出たとき）

1. WordPressの下書きを開いて読む。誤字・事実誤りがないか30秒見る
2. アイキャッチ画像を付ける（`CLAUDE.md` のプロンプトをChatGPTに投げる）
3. 公開する
4. `workspace/threads/今日の日付.md` を開く
5. Threads投稿文をコピー → **自分の言葉に手直しして** Threadsに投稿
6. ビジュアル案に沿った画像を作って添える
7. noteに記事を載せる場合は、note タイトル案を使う

> 手直しは必ずやる。前回勝った投稿も「ツール出力をあなたが直したもの」だった。

---

## 5. 案件が承認されたとき（1コマンド）

ASPで提携が承認されたら、アフィリエイトリンクのHTMLをコピーして：

```bash
cd affiliate-research-engine/playbook/scripts

# まず何が変わるか確認（ファイルは変更されない）
python promote_program.py \
  --key sapuri_toeic \
  --name "スタディサプリENGLISH TOEIC" \
  --topic toeic --asp A8 --reward 3000 \
  --link '<a href="ここにASPからコピーしたリンクHTML">→ 無料体験を見る</a>' \
  --dry-run

# 問題なければ --dry-run を外して実行
```

これで5つが自動更新される：

| ファイル | 何が変わる |
|---|---|
| `affiliate_inserter.py` の `LINKS` | リンクが登録される |
| `affiliate_inserter.py` の `TOPIC_MAP` | そのトピックの**主力**になる（最大2件） |
| `CLAUDE.md` | 稼働中リストに載る（次回以降のAIが認識する） |
| `program_candidates.csv` | `candidate` → `approved` |
| `keywords.csv` | `--keywords` を渡せば記事ネタが補充される |

**以降、そのトピックの記事を書くと自動でリンクが入る。**

### `--topic` に指定できる値

`toeic` / `coaching` / `pronunciation` / `training` / `eikaiwa` /
`study_abroad` / `workingholiday` / `agent` / `philippines` / `domestic` / `default`

## 6. ネタ切れを防ぐ

記事ドラフターは `playbook/workspace/keywords.csv` の `status=todo` から1件ずつ消費する。
**todoが0になると記事生成が止まる。**

```bash
# 残りを数える
grep -c ',todo,' affiliate-research-engine/playbook/workspace/keywords.csv
```

現在17件（3日ごと消費なので約1.5ヶ月分）。5件を切ったら補充する。
補充は「案件の方向を循環させる」こと（TOEIC系→留学系→フィリピン系→…）。

---

## 7. 困ったとき

| 症状 | 原因と対処 |
|------|-----------|
| 何も動かない | ワークフローが**mainブランチに無い**。定期実行はmainのものしか動かない |
| 記事が生成されない | `keywords.csv` の todo が枯れた → 補充する |
| 記事にアフィリンクが入らない | タイトルに判定キーワードが無い。`affiliate_inserter.py` の `classify()` を見る |
| すぐ試したい | Actions画面 → 該当ワークフロー → 「Run workflow」で手動実行できる |

---

## 8. やってはいけないこと

- **ASPの管理画面をスクレイピングさせない**（BAN対象）。案件収集は公開情報のみ
- **未承認の案件のリンクを作らない**。承認されてから `promote_program.py` で登録する
- 生成物をノーチェックで公開しない。事実誤りと誇大表現だけは人間が見る
