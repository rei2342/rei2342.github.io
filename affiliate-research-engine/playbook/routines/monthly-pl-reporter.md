# Routine: Monthly P&L Reporter（テク34）

月次の収益レポートを自動生成する。

## スケジュール
毎月1日 08:00

## プロンプト
```
①Notion MCP で「案件管理」DBから前月の全データを取得する。
  Notion未接続なら ./workspace/keywords.csv と手元の収益CSVを使う。
②発生額 / 確定額 / 承認率 / 案件別の貢献度 を集計する。
③前月比 / 前年同月比 を算出する(グラフ化できるなら表＋簡易グラフ)。
④ハイライト3つ・課題3つ・来月の重点アクション3つを抽出する。
⑤./workspace/reports/YYYY-MM.md として保存し、Slackに通知する。
⑥承認率が直近3ヶ月で下落している案件があれば、原因仮説を3つ添える(第9章テク38に接続)。
```

## 依存
- 任意: Notion/Sheets MCP（なければ手元CSV）
- 任意: Slack MCP
