# 第3章 記事量産 — 1日1本のドラフトが、勝手に積み上がる

## 9. SERP Reverse Engineering — 上位記事を分解して再構築する

- **使うとき:** 記事を書く前。上位の構造を抜き取り、抜け穴を埋める
- **出力:** 上位を抜くための独自見出し（H2×6 / H3×各3）

```
以下のキーワードで検索上位10件のタイトルと見出し構造を分析してください。

①共通する見出し構造
②よく言及される論点トップ5
③どこにも書かれていない疑問・抜け穴を5つ

この情報をもとに、上位を抜くための独自構造の見出し案を
H2×6、H3×各3本で出してください。

キーワード:{{キーワード}}
```

## 10. Skeleton-Then-Fill — 骨組みを並列で作り、中身を肉付けする

- **使うとき:** 長文記事を失速させずに書ききる
- **コツ:** Claude Code の Subagent（並列ワーカー）で各H2を同時に走らせる

```
以下のテーマで、見出しスケルトン(H2×5、各H2にH3×3)を
先に全部並べてください。

次に、各H2を1つずつ独立タスク(Subagent)として扱い、
各セクション800字で肉付けしてください。

最後に全体を統合し、論理の重複と矛盾だけを潰した完成版を提示してください。

テーマ:{{テーマ}}
```

## 11. E-E-A-T Injection — 経験と専門性を後から差し込む

- **使うとき:** AIドラフトに「実体験」を後付けする（Google評価対策）
- **出力:** 不足箇所と、そこに差し込む具体的な一文（数字・固有名詞・実体験）

```
以下のドラフト記事を、E-E-A-Tの観点で評価してください。

①Experience(実体験)
②Expertise(専門性)
③Authoritativeness(権威性)
④Trustworthiness(信頼性)

各観点で不足箇所を3つずつ列挙し、
そこに差し込む具体的な一文(数字・固有名詞・実体験エピソード)を生成、
「ここに差し込む」と位置を指示してください。

ドラフト:{{ドラフト本文}}
```

---

## 12. Internal Link Web Designer — 内部リンク網を構造で設計させる

- **使うとき:** 記事が10本を超えて内部リンク設計が滞ったとき
- **出力:** ピラー/クラスター/サテライト3層分類＋各記事の内部リンク（最大5本）

```
以下のURLリストと各記事のタイトル一覧を読み込み、
トピッククラスター構造で内部リンクマップを設計してください。

「ピラー記事」「クラスター記事」「サテライト記事」の3層に分類し、
各記事から張るべき内部リンクを最大5本ずつ表で出してください。
アンカーテキスト案も併記してください。

URLリスト:{{URL+タイトル一覧}}
```

---

## 13. Comparative Review Stack — 比較レビューを構造で量産する

- **使うとき:** 高単価×比較レビュー（相性抜群）を固定構造で量産
- **出力:** 主役を入れ替えた同一構造の比較記事3本

```
以下の3商品について、同一構造の比較レビュー記事を3本生成してください。

各記事の主役を1商品ずつ変え、他2商品は「比較対象」として登場させます。

記事構造は固定:
・導入(150字)
・主役商品の総評
・3軸での比較表(価格・効果・サポート)
・主役商品が刺さる人/刺さらない人
・結論

商品リスト:{{商品3つ}}
```
