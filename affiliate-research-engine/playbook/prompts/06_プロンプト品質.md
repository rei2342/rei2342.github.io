# 第6章 プロンプトの中身を磨く — 出力の質を、毎回安定させる5つ

> 「何を作るか」は決まった。ここは品質を毎回安定させる型。第3〜5章のプロンプトに重ねて使う。

---

## 22. Output-First Specification — 完成形のテンプレを先に固定する

- **使うとき:** 出力のブレを消したいとき（「記事を書いて」を卒業する）

```
以下のテンプレを完璧に埋めてください。

タイトル:[40字以内・数字入り]
導入:[読者の悩み3つを各1文]
本論:[H2×3+各300字]
結論:[行動提案1つ]
CTA:[15字以内]

テーマ:{{テーマ}}
```

---

## 23. Negative Constraints — AI臭を消すNGリスト ★全生成に常時併用

- **使うとき:** 文章を生成するすべての場面に貼り足す
- これは単独で使うより、第3〜5章のプロンプト末尾に毎回くっつけるのが正しい使い方。

```
以下を作成してください。禁止事項は厳守。

①「〜について」「〜することが大切」禁止
②3文字熟語の連発禁止
③冒頭の挨拶禁止
④箇条書きの羅列で逃げるの禁止
⑤同じ語尾を3回連続使用禁止

違反したら全文書き直してください。

作成対象:{{作成対象}}
```

---

## 24. XML Structured Tagging — 情報をタグで分離する

- **使うとき:** ゴール・背景・制約・例・形式をまとめて渡すとき（読解精度が上がる）

```
以下の構造で指示します。各タグの中身に沿って回答してください。

<goal>達成すべきゴール</goal>
<context>背景情報</context>
<constraints>禁止事項</constraints>
<examples>参考例</examples>
<output_format>出力形式の枠</output_format>
```

---

## 25. Self-Refine — 生成・批評・改稿を1回で走らせる

- **使うとき:** 1レスポンスで「初稿→辛口採点→改稿」まで終わらせる

```
以下のお題について、3ステップを1レスポンスで全部やってください。

①初稿を書く
②辛口編集者として、説得力・独自性・論理性・読みやすさ・抜け漏れ
  の5観点で採点する
③採点を踏まえた改稿版を書く

お題:{{お題}}
```

---

## 26. Calibrated Confidence Prompting — 確信度を明示させる

- **使うとき:** 事実誤認が命取りになる高単価ジャンルで、主張の信頼度を可視化

```
以下の質問に答える際、各主張に必ず「確信度0-100%」を併記してください。

・50%未満 → 「推測」
・70%以上 → 「事実」

ラベル付けし、各確信度の根拠を1行で示してください。

質問:{{質問}}
```
