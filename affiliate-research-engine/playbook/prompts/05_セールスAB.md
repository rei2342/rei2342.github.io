# 第5章 セールス文の自動AB — 1本に賭けず、5本で測る

> 最初から完成形は出ない。5本走らせて勝者だけ残す。当てにいくのではなく、当たりを引き当てる。

---

## 18. Variant Spawner — 同じLPで5パターン生成する

- **使うとき:** ファーストビューのCVRを上げる（手で書き分けない）
- **出力:** キャッチ+サブ+CTAだけ変えた5バリアント（訴求軸を明確に分ける）

```
以下のLP本文を読み込み、ファーストビューの
「キャッチコピー+サブコピー+CTAボタン文言」だけを変えた
5バリアントを生成してください。

各バリアントの訴求軸を明確に変えてください。
例:恐怖訴求/利得訴求/権威訴求/共感訴求/緊急性訴求

各案について、刺さる読者層も併記してください。

LP本文:{{LP本文}}
```

---

## 19. Objection Handler — 反論処理パートを自動増殖する

- **使うとき:** 離脱ポイント（高い/できるか不安/今じゃない）を潰す
- **出力:** 想定反論10個＋各200字以内の反論処理文

```
以下の案件について、購入前の想定反論を10個列挙し、
それぞれの反論処理文を生成してください。

押し売り感を出さず、読者の不安を一度受け止めてから、
データや事例で解消する構造にしてください。

各反論処理は200字以内。

案件:{{案件}}
```

---

## 20. Urgency Calibrator — 緊急性と希少性を数値で調整する

- **使うとき:** 煽りすぎず薄すぎず、ちょうど効く強度を探す
- **出力:** 弱/中/強の3水準×各3パターン＋想定反応（成約率と嫌悪感）

```
以下のオファーについて、緊急性と希少性の演出を
弱・中・強の3水準で書き分けてください。

各水準でCTA周辺の文章を3パターン生成し、
想定される反応(成約率の上下/嫌悪感の発生有無)も併記してください。

オファー:{{オファー}}
```

---

## 21. Story Arc Injector — ストーリー型LPを構造で組む

- **使うとき:** 高単価で論理だけでは売れないとき、感情を動かす
- **出力:** 6段階ストーリーアーク（各200字）＋LP挿入位置の提案

```
以下のペルソナと案件に合うストーリーアークを生成してください。

構造は6段階:日常 → 事件 → 葛藤 → 出会い → 転換 → 成功
各段階200字、登場人物は1人、感情の起伏を明示してください。

最後に、このストーリーをLPのどこに挿入すべきかも提案してください。

ペルソナ:{{ペルソナ}}
案件:{{案件}}
```
