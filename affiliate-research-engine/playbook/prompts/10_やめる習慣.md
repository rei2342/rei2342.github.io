# 第10章 やめたほうがいい3つの習慣 — 引き算で伸びる

> 自動化で伸びる人と伸びない人の差は、自動化の中身ではなく「やめられる習慣」のほうにある。

---

## 40.「100記事書いてから考える」をやめる

- 100記事の前に、**5記事で勝ち筋を見つけて、その勝ち筋だけ増やす**。
- Claude Code で5記事を高速検証できる時代。書き始める前に、**測る指標を必ず設計する**。
- 実装: 第5章のバリアント検証（テク18）→ 勝者を `../CLAUDE.md` の `検証結果` に記録 → 勝ちパターンだけ第3章で量産。

## 41.「単発の自動化」をやめる

- 記事生成だけ自動化しても、SNS・分析・レポートが手動ならボトルネックが移るだけ。
- 第8章の5つ（テク31〜35）は、**最低3つはセットで動かす**。
- 推奨セット: テク31（毎朝ドラフト）＋テク32（毎日SNS）＋テク35（不調検知）。

## 42.「人間の最終チェックを省く」をやめる ★最重要

- Claude Code は平均的な間違いはほぼしないが、**致命的な間違いを年に数回やる**（コンプラ違反・誤った数字・案件名の誤記）。
- どれも公開前の30秒の目視で防げる。**最終ゲートだけは人間が握る**。
- 実装: 第9章テク36（コンプラ）＋テク37（承認率）を通した後、必ず人間が1回見る。これを省かない。
