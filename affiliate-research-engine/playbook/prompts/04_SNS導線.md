# 第4章 SNS導線 — X→note→LINEのバトンを、自動でつなぐ

> 検索流入だけでは波がある。Xで集め、noteで温め、LINEで締める3段リレー。

---

## 14. Hook Library Builder — 過去のバズ投稿から訴求パターンを抽出する

- **使うとき:** 自分専用のフックテンプレ集を作る（最初の1回＋定期更新）
- **入力:** エンゲージメント率3%以上の投稿一覧
- **出力:** フック構文10種（穴埋めテンプレ付き）→ `../workspace/content-bank/` に保存

```
以下のX投稿一覧(エンゲージメント率3%以上)を分析し、
共通する「フック構文」を10種類抽出してください。

各構文について
・使われる場面
・期待される反応
・汎用テンプレ(穴埋め形式)
を表で出してください。

投稿一覧:{{投稿一覧}}
```

---

## 15. Thread-to-Article Bridge — XスレからnoteへのCTAを自動生成する

- **使うとき:** Xで引いた読者をnoteへ送る（流入率の8割がここ）
- **出力:** スレ末尾CTA 3パターン（各140字以内・押し売り感なし）

```
以下のXスレッドの内容を読み、note記事への自然なCTAを3パターン生成してください。

①続きが気になる型
②読者の悩みを言語化する型
③ベネフィット明示型

それぞれ140字以内、押し売り感なし、
最後の一文に「note記事のリンクを置く」前提で書いてください。

スレッド:{{スレッド本文}}
```

---

## 16. Lead Magnet Generator — LINE登録特典を量産する

- **使うとき:** LINEリストの登録率を上げる特典を作る
- **出力:** 特典案10個＋制作コスト対効果ランキング

```
以下のペルソナに対し、LINE登録を促すリードマグネット案を10個生成してください。

各案について
・特典名(20字以内)
・中身の概要
・想定登録率
・制作にかかる時間
を出し、最後に制作コスト対効果でランキングしてください。

ペルソナ:{{ペルソナ}}
```

---

## 17. Follow-up DM Script — 登録後の追いラインを自動生成する

- **使うとき:** 登録直後3日の離脱を防ぐ
- **出力:** 追いライン5通（お礼→共感→比較→社会的証明→オファー）

```
以下のペルソナに対し、LINE登録後の追いライン5通を生成してください。

1通目=即時のお礼+期待値設計
2通目=共感ストーリー
3通目=他社/独学との比較
4通目=社会的証明
5通目=オファー提示

各通の冒頭は、スタンプ反応で分岐できる構造にしてください。

ペルソナ:{{ペルソナ}}
案件:{{案件}}
```

---

### この章のゴール
X→note→LINEのリストが積み上がる。テク14のフック集は `../workspace/content-bank/` に置き、
第8章テク32（Daily SNS Cannon）がそれを参照して毎日X投稿を自動生成する。
