# 第7章 MCPで手足をつける — 入れておきたい4つ

> MCP(Model Context Protocol) = AIを外部サービスにつなぐ標準規格。
> ここから Claude Code は「コーディングツール」から「現実を動かすエージェント」に変わる。
> セットアップは `../mcp/SETUP.md` と `../mcp/mcp.example.json` を参照。

---

## 27. Firecrawl MCP — 競合LPとサイトを丸ごとMarkdown化する

- **何:** Webページを構造ごとMarkdown化して読ませる
- **使うとき:** 競合分析（第2章テク8 Counter-Offer と直結）

```
以下のURLをFirecrawlでMarkdown化し、
第2章のテクニック8(Counter-Offer Generator)を適用して、
真逆の角度から訴求するLP構成案を3本出してください。

URL:{{URL}}
```

---

## 28. Supadata MCP — 動画から訴求要素を一発抽出する

- **何:** 動画のトランスクリプトを取得して渡す
- **使うとき:** 伸びている動画の構成を分解して、LPやスレに転用

```
以下の動画URLからトランスクリプトを抽出し、
視聴維持を生んでいる「フック構文」と「離脱回避ポイント」を
5個ずつ抽出してください。

URL:{{動画URL}}
```

---

## 29. Memory MCP — Claude Codeに永続的な記憶を持たせる

- **何:** ペルソナ・案件・検証結果を永続化（毎回前提を貼り直す作業がゼロに）
- **併用:** プロジェクト直下の `../CLAUDE.md` も自動読み込みされる。両方使うとさらに強い。
- このリポジトリでは `../CLAUDE.md` が「貼り直し不要のメモリ」の実体になっている。

```
以下の情報を永続記憶に登録してください。

①扱っているジャンル{{ジャンル}}
②主要ペルソナ{{ペルソナ}}
③稼働中の案件と単価{{案件と単価}}
④NGの訴求軸{{NG軸}}

今後のセッションでは、毎回これを最初に参照してから作業してください。
```

---

## 30. Notion/Sheets MCP — 案件管理と収益データを一元化する

- **何:** Notion / スプレッドシートと直接やり取り
- **使うとき:** 収益データの集計→分析→次の打ち手（第8章テク34 月次レポートが依存）

```
NotionのDB「案件管理」から、当月の発生件数と確定件数を取得し、
ASP別/案件別に集計してください。

承認率が直近3ヶ月で下落している案件を抽出し、
原因仮説を3つずつ立ててください。
```

---

### この章のゴール
読む(Firecrawl/Supadata)・覚える(Memory)・動かす(Notion/Sheets)がそろう。
これが揃って初めて、第8章 Routines が「現実を動かす自動運転」になる。
