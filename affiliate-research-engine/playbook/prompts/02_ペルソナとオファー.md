# 第2章 ペルソナとオファー設計 — たった1人を、深く仕留める

> 「みんなに売る」は売れない。「1人に深く刺す」が結果的に多くに届く。

---

## 5. N=1 Persona Generator — 実在しそうな1人を生成する

- **使うとき:** 案件確定後、最初に「誰に書くか」を固める
- **出力:** 氏名〜決済を渋る瞬間までの高解像度ペルソナ1名

```
以下のジャンルで購入してくれる典型的な顧客を1名、
実在しそうな解像度で生成してください。

・氏名/年齢/性別/居住地
・職業/年収/家族構成/趣味
・直近3ヶ月の悩み5つ
・購入直前に検索する3つのキーワード
・決済を躊躇する3つの理由
・決済を後押しする3つのトリガー

一般論は禁止、具体名で書いてください。

ジャンル:{{ジャンル}}
```

---

## 6. Pain-Stack Mapping — 悩みを5層に分けて積み上げる

- **使うとき:** ペルソナ確定後、コピーで撃つ層を決める
- **入力:** テク5で作ったペルソナ
- **出力:** 表層〜理想の5階層×各3つ＋撃つべき層の提案

```
このペルソナの悩みを以下の5階層で構造化してください。

①表層(本人が普段口にする悩み)
②中層(まだ言語化できていない不満)
③深層(根本原因)
④恐怖(放置した場合の最悪シナリオ)
⑤理想(本当はどうなりたいか)

各層3つずつ書き、最後に
コピーで刺すべき層はどこかを、根拠つきで提案してください。

ペルソナ:{{テク5の出力を貼る}}
```

---

## 7. Offer-Market Fit Test — オファーと市場の一致度を採点する

- **使うとき:** 案件をそのまま売る前に、刺さるか検算する
- **出力:** 10項目採点と判定（70未満=ピボット / 70-85=再設計 / 85以上=即実行）

```
以下のペルソナ情報と案件情報を読み、
両者の一致度を10項目で採点してください。

各項目10点満点、合計点を出してください。
・70点未満 → 「ピボット推奨」
・70-85点 → 「オファー再設計」
・85点以上 → 「即実行」

判定理由も箇条書きで書いてください。

ペルソナ:{{ペルソナ}}
案件:{{案件情報}}
```

---

## 8. Counter-Offer Generator — 既存LPの真逆を作って差別化する

- **使うとき:** 後発で参入するとき、先行と同じ訴求軸を避ける
- **入力:** ライバルLP（URLまたは本文）
- **出力:** 主要訴求軸3つ＋それぞれの「真逆訴求」案

```
以下のライバルLPを読み込み、主要な訴求軸を3つ抽出してください。

次に、その3つすべてに対して
「真逆の角度から正当化できる訴求」を生成してください。

各案について
・どんな読者層に刺さるか
・実装上の注意点
も併記してください。

ライバルLP:{{URLまたは本文}}
```

> Firecrawl MCP（第7章）を入れていれば URL を直接読ませられる（テク27と同じ流れ）。
