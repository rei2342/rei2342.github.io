# 第1章 案件選定 — 月50万の8割は書く前に決まる

> 感覚で選ぶのをやめて、数字で選ぶ。`{{ }}` を自分の値に置き換えて、上から投げる。

## 1. Tier-S Niche Sniper — ジャンルを3軸でふるいにかける

- **使うとき:** 参戦ジャンルを絞り込むとき（最初の1回）
- **入力:** ジャンル候補のリスト
- **出力:** 合計24点以上の「参戦候補」だけのランキング

```
あなたは高単価アフィリエイトの市場分析家です。
以下のジャンル候補を、3軸で10点満点採点してください。

①平均単価(1万円以上=高得点)
②承認率(50%以上=高得点)
③月間検索ボリュームと競合密度のバランス

各軸の根拠を1行ずつ添え、合計点が高い順に並べてください。
最後に、合計24点以上のジャンルだけを「参戦候補」として残してください。

ジャンル候補:{{ジャンル候補をカンマ区切りで}}
```

## 2. ASP Cross-Crawl — 同じ商品を複数ASPで横並びにする

- **使うとき:** 案件を確定する前に、最も条件の良いASPを選ぶとき
- **入力:** 商品名
- **出力:** ASP横断比較表（単価・承認条件・承認率・特単交渉可否）

```
以下の商品名について、A8/もしも/afb/アクセストレード/
ValueCommerce/Catsの主要ASPを横断的に調べ、表で出してください。

列は「ASP名/単価/承認条件/承認率の目安/特別単価交渉の可否」。
出典が確認できないものは「不明」と書き、推測で埋めないでください。

商品名:{{商品名}}
```

> MCP（第7章 Firecrawl）を入れていれば、ASPの公開ページを直接読ませて精度を上げられる。

## 3. LTV Reverse Calculator — 月50万を「12ヶ月維持」から逆算する ★最初に投げる1本

- **使うとき:** いちばん最初。憧れを「今日やること」に変える
- **入力:** なし（目標額は固定50万）
- **出力:** 単価×成約数×アクセス×記事数の現実的な5パターン＋12ヶ月維持しやすい順ランク

```
月50万円の売上を「12ヶ月安定して維持する」前提で、
現実的な組み合わせを5パターン出してください。

各パターンで以下を表にしてください。
・想定単価
・必要成約数(月)
・必要アクセス数(成約率1%/3%/5%の3水準)
・想定記事数(1記事の平均月間PVを500/1500/3000で)
・最大依存案件が終了した場合の影響額(%)

最後に、1案件依存度が低く、12ヶ月続けやすい順にランクづけしてください。
```

## 4. Sustainable Demand Index — 持続需要を数値化する

- **使うとき:** 参戦候補が複数残ったとき、流行ではなく定常需要を選ぶ
- **入力:** キーワード群
- **出力:** 「需要 ÷ 飽和度 × 持続性」指数のランキング＋上位5つの維持根拠

```
以下のキーワード群について、3軸で採点してください。

①需要スコア(0-10:月間検索ボリューム)
②飽和度スコア(0-10:競合の強さ)
③持続性スコア(0-10:Google Trendsで直近3年が平坦または上昇基調なら高得点)

「需要 ÷ 飽和度 × 持続性」の指数を計算し、高い順に並べてください。

上位5つに対して、
「12ヶ月安定して上位を維持できる根拠」と
「想定される競合の動きへの対処」を3行ずつ書いてください。

キーワード群:{{キーワードをカンマ区切りで}}
```
