# Playbook — 高単価アフィを月50万・12ヶ月安定させる運用システム

ドキュメント「Claude Codeで高単価アフィ 月50万・12ヶ月安定」を、
**そのままコピペで動く実装**に落とし込んだもの。約40プロンプト＋自動運転＋MCP＋公開前ガード。

人間がやる作業を最小に、Claude Code がやる作業を最大に。
あなたに残るのは「方向の判断」と「最終ゲートのチェック」だけ。

---

## まず今日やること（15分）
`prompts/01_案件選定.md` の **テク3（LTV Reverse Calculator）** をコピペして投げる。
月50万が「単価 × 成約数 × アクセス」にどう分解されるかが目の前に出る。
→ その後はこのREADMEの順に進める。

## 10章の流れ（全部つながっている）
```
1 案件選定 ─→ 2 ペルソナ/オファー ─→ 3 記事量産 ─→ 4 SNS導線 ─→ 5 セールスAB
   （数字で選ぶ）   （1人に深く刺す）     （毎日1本）    （X→note→LINE） （5本で測る）
                                            │
6 プロンプト品質（全生成に重ねる）←─────────┘
7 MCP（手足）→ 8 Routines（自動運転：寝てる間に1〜5が回る）
9 落とし穴（自動化前に潰す）→ 10 やめる習慣（引き算で伸びる）
```

## 永続メモリ
`../CLAUDE.md`（このリポジトリ＝`affiliate-research-engine/`直下）が、
ジャンル・ペルソナ・案件・NG軸を保持する。セッションをまたいで前提を貼り直さなくていい。
値が決まったら CLAUDE.md を更新する。

## 既存資産との関係
- 下層ツール: `../main.py` / `../analyzers/` / `../generators/`（案件分析・投稿生成）
- 既存コンテンツ: `../outputs/`（転職/OLの note・SNS 資産）= 第1の実装ジャンル
- playbook はそれらの上に乗る「月50万を12ヶ月安定させる運用レイヤー」。

## 公開前に必ず
記事を出す前に `compliance/README.md` の2ゲート（薬機法/景表法＋承認率）を通し、
最後に人間が30秒目視する（テク42）。ここだけは自動化しない。

## 次のアクション
`SETUP_CHECKLIST.md` の「判断に迷っている点」に答えると、
CLAUDE.md と Routines を実値で埋めて即稼働状態にできる。
