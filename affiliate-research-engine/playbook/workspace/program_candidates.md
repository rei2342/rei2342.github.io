## 却下対策の結論（先に読む）

A8で英語コーチング系（LIBERTY / スピークAI / 夢カナ留学）が**全却下**されたのは、A8公開情報が示す否認理由「**記事数が僅少 / 案件との親和性が低い新規サイト**」に合致した可能性が高い（[推測]）。
→ だから申請は **段階戦略**でいく：

1. **第1波（今すぐ）**: 即時提携・自動承認が期待できる**無料体験系オンライン英会話 + スタディサプリ**を一斉申請
2. **原体験づくり**: 承認された案件をセルフバックで自分が体験 → 「使ってみたレビュー」記事を5〜10本公開
3. **第2波（記事が溜まってから）**: 却下された**高単価コーチング（RIZAP / プログリット / トライズ）**へ再申請

## 申請前チェックリスト（却下を繰り返さないため）

1. **記事の下限を作る（最優先）**: 申請前に最低5〜10本・各1,500字以上の英語学習/留学の実体験記事を公開。特に「無料体験してみた」レビューが親和性の証明になる。空サイト・1〜2記事のまま再申請しない。
2. **申請順を分ける**: 即時提携・低難易度（1〜8, 11）を先に通す → 承認案件で記事を増やす → 却下された高単価（10, 12, 13）に再申請。
3. **セルフバックで原体験+初報酬を先取り**: スタサプ / レアジョブ /（可なら）RIZAPの無料カウンセリングを自分で体験 → レビュー記事化 → 次の審査の信頼性が上がる二重効果。
4. **運営者情報を整える**: 「27歳・営業事務・英語やり直し中の田中さくら」プロフィール + プライバシーポリシー + 問い合わせを設置。ジャンルを英語学習に一本化（無関係記事を混ぜない）。
5. **審査コメント文例**（提携申請の自由記入欄・空欄で出さない）:
   > 「27歳・営業事務として英語をやり直す実体験ブログを運営しています。読者は20〜30代の英語初心者で、オンライン英会話/TOEIC/留学の比較・体験レビューを継続発信中です。御社サービスは無料体験を実際に受けたうえで、料金・レッスンの流れ・初心者目線の使い勝手を記事化して紹介予定です。誠実なレビューで貢献します。」

   → **(1)ジャンル親和性 (2)読者像 (3)自分が体験して書く旨 (4)継続発信** の4点を必ず含める。
