# note旧ルール と さくら現行ルール の差分（2026-08-09）

3列で並べます。**3列目が判断の根拠**です。ルールどうしの比較だけでは、
どちらが正しいか決まりません。

| 項目 | note用（`headerArtDirection`） | ブログ用（8/7の固定テンプレート） | 公開画像の実態（51枚） |
|---|---|---|---|
| **人物** | 毎回は出さない。出すなら後ろ姿・手元・俯瞰。顔を作り込まない | 毎回ちびキャラを出す（固定） | 8/7の31枚のうち**12枚は人物なし**。Aに選んだ13枚も人物あり5・なし8で拮抗。**noteのルールに近い** |
| **画風** | 温かい手描き。水彩・色鉛筆タッチ | Kawaii chibi anime / flat illustration | 8/1〜05の14枚は水彩で、**Aの13枚すべてがこの系統**。ちびキャラは全部C |
| **色** | 生成り・ベージュ・くすみピンク・グリーン・自然光 | パステルピンク一色 | 実物は淡い桜色＋クリーム＋白。**noteとブログの中間**で、これが一番きれいに見える |
| **文字** | **一切入れない** | ノートに `[TEXT]` を描かせる | ノートの文字は判読不能な線になっている例が多い。読める例（546の「90日達成」）は**削除対象の主張**になっていた |
| **数字** | 指定なし（文字を入れないので発生しない） | 「数字を1つ入れると対応が分かりやすい」 | **32・282・304・546が捏造扱いになった直接の原因**。推奨をやめる根拠がある |
| **小物** | 記事ごとに変える | マグ・うさぎ・ペン立て・ノートを固定 | 固定4点が揃うのは31枚中9枚。**揃った9枚は全部C**（記事の差が消える） |
| **姿勢** | 指定なし | 「机に座る」で固定 | Aの人物あり5枚のうち、机に座っているのは1枚（297）。**電車・布団・街角がAに入っている** |
| **比率** | 1.91:1 | テンプレは16:9／運用手順は1200×630（＝1.91:1） | **矛盾したまま。実物は16:9** |
| **表情・ポーズ・年齢感** | 「顔を作り込まない」だけ | 指定なし | 指定が無いので毎回ぶれる。Aの5枚は偶然そろっただけ |
| **参照画像** | なし | なし | **人物を固定する仕様なのに参照画像が無い**。同一人物性が担保されていない |

## 差分から言えること

1. **矛盾している6項目（人物・画風・文字・数字・小物・姿勢）は、すべてnote側が実態と合っています。**
   ブログ用の固定ちびキャラは、公開画像の品質比較を経ていない新ルールで、
   実際に適用されたのは31枚中9枚。その9枚はA判定が1枚もありません。

2. **「数字を1つ入れる」は実害が出た項目です。** 32・282・304・546の4枚は、
   この推奨があったために架空のスコアや達成日数が焼き込まれ、削除対象になりました。

3. **参照画像が無いまま人物を固定した**のが、同一人物性が崩れた原因です。
   ちびキャラ9枚どうしでも顔が揃っていません。

4. 比率は**マスターを16:9にして、noteは書き出しでクロップ**すれば両立します。
   どちらかを捨てる必要はありません。
