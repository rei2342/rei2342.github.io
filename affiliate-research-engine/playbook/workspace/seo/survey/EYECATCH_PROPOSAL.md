## D. 正式仕様案

### D-1. 固定（記事をまたいで1文字も変えない）

| 項目 | 値 |
|---|---|
| 画風 | やわらかい手描きの水彩・色鉛筆調。線は細く柔らかい。フラットなベタ塗りにしない |
| 禁止画風 | 写真・実写風・3Dレンダリング・ちびアニメ（頭身の低いデフォルメ） |
| 基本配色 | 淡い桜色 / クリーム / 白。彩度を上げない |
| 光 | やわらかい自然光。強い影とコントラストを作らない |
| 人物（出す場合） | 日本人女性。大人（20代後半〜30代前半に見える）。肩までのブラウンの髪。桜の小さなヘアクリップ1点。クリーム・淡いグレーの清潔な服に桜色を1点。**顔は作り込まない**（横顔・伏し目・後ろ姿・手元・俯瞰）。教える表情にしない |
| 人物の位置 | **中央から右**。腰から上、または手元のみ |
| 文字セーフエリア | **左半分（0〜600px）**。ここに人物・主要な小物を置かない。上下左右40pxは何も置かない |
| 画像内の文字 | **画像生成AIには一切描かせない。** 生成後に固定フォントで合成する |
| 比率 | マスター 16:9（1920×1080で生成 → 1200×675へ縮小） |
| 禁止事項 | 年齢／スコア／金額／期間／「成功・伸びた・改善した」／使ったと誤認させる画面／ロゴ・UI／旧サイト名／旧人物設定／本文にない数字や結論／読めない小さな文字 |
| 生成プロンプト末尾 | `No letters, no words, no numbers, no logos, no watermarks.` を必ず入れる |
| 参照画像 | E で選んだ候補を毎回同じものとして渡す |

### D-2. 記事ごとに変える

場面／表情／ポーズ／カメラ距離（寄り・引き・俯瞰・手元）／背景／小物／
カテゴリ差し色／リード文言／補助文言／alt／ファイル名

**「机に座る」を固定しません。** 電車・玄関・台所・窓辺・床・立ち姿を選べるようにします
（Aに選んだ273・521・289が、その効き目を示しています）。

### D-3. 媒体共通のマスター＋媒体別の書き出し

```
  マスター（文字なし・16:9・1920×1080）
        ├─ ブログ用 1200×675 … 左半分に固定フォントで見出しを合成
        └─ note用  1.91:1     … 中央から右を残して安全にクロップ・文字なし
```

- 同じ記事でブログ用とnote用を別々に生成しない（人物が別人になる原因）
- 人物と主要な小物を中央から右に置くので、note用に左を切っても主題が残る
- 文字は合成なので、**画像AIに日本語を描かせる問題が消えます**

比率の食い違いは、**マスターを16:9にして、noteは書き出しでクロップ**で解消します。
