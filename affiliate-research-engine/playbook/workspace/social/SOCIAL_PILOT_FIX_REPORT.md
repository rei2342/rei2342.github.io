## 2. subset_gate を命題の照合にした

`scripts/social_claims.py` を新設し、`subset_gate` から呼びます。
数字の一致だけでは、記事に無い**因果・診断・効果**が通ってしまうためです。

SNS文を文と箇条書きの単位へ割り、公開本文の文と突き合わせます。見るのは4つ。

| 見るもの | やり方 |
|---|---|
| 対象 | 内容語の重なり（0.5以上で対応づけ） |
| 行動 | 読者にさせる操作か、事実の主張か（モダリティ）|
| 極性 | 記事が否定していることを肯定していないか（0.7以上の重なりで判定）|
| モダリティ | 記事が「確認項目・可能性」としているものを言い切っていないか |

判定は `ok / declared / unsupported / contradiction / overclaim` の5つ。
後ろの3つが1つでもあれば落とします。

**誤検知を減らすために入れた歯止め**（どれも実際に誤検知が出たので入れました）

- 箇条書きは操作か項目として扱い、言い切りとして見ない
- 「ではなく」は対比なので否定に数えない
- 内容語が3語未満の文はモダリティも極性も判定しない（何にでも高く一致するため）
- 「記事のほうに置いています」のような案内文は主張として扱わない

記事に無い判断を足したいときは、下書きの `inferences` に文と根拠を宣言し、
**弱めた形でだけ**通します（言い切っていたら `overclaim` で落とします）。

## 3. 8つの言い切りを弱めた

| 前 | 後 |
|---|---|
| 直し方まで返ってくるかで足りるかが分かれる | 軸にしやすいのは、返ってくるものの中身です |
| 自分で気づける範囲なら点数だけで足りる | 自分で間違いに気づける範囲かどうかは、比べるときの材料の1つになることがあります |
| 気づけない部分には人の目が要る | （削除。記事に無いので使わない） |
| 内容を言えるのに落とすなら保持の問題 | 言えるのに設問で落ちるなら、聞き取りではなく、聞いた内容が残っていないほうかもしれません |
| 言えない再生時間は入力になっていない | 言えない回が多いなら、その時間は…入力になっていない可能性があります |
| 1時間あたりの費用で早いか分かる | 1時間あたりで出るのは触れる時間あたりの費用で、上達の速さを保証するものではありません |
| レッスン中なら教材や講師、予約画面なら手数が原因 | 授業中で止まっていたなら…相性のほうかもしれません。予約の前で閉じていたなら…回数のほうかもしれません |
| 手数が減らなければ同じ場所で止まる | 回数が減っていないなら、続けるコツを足しても同じ場所で止まることがあります |
