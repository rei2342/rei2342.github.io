## 7. 追加する成果物の完成形

### 比較表（H2「費用と時間を、混ぜずに並べる」）

**4つを1つの列にしない。** 混ぜると「1時間あたりが安い＝早い」に読めてしまう。

```
確認項目：候補を3つまでに絞って、この表を埋める。
左の3列は数えられます。いちばん右の列は、数えられません。

┌──────────┬────────────┬──────────┬────────────┐
│          │ ① 費用総額   │ ② 英語に   │ ③ 1時間あたり │
│          │            │ 触れる時間  │ （① ÷ ②）   │
├──────────┼────────────┼──────────┼────────────┤
│ 候補A     │            │          │            │
│ 候補B     │            │          │            │
│ 候補C     │            │          │            │
└──────────┴────────────┴──────────┴────────────┘

┌──────────┬──────────────────────────────────┐
│          │ ④ 上達の速さ                        │
├──────────┼──────────────────────────────────┤
│ 候補A     │ **この表では出せない**                │
│ 候補B     │ **この表では出せない**                │
│ 候補C     │ **この表では出せない**                │
└──────────┴──────────────────────────────────┘

**④を③と同じ表に置かないのは、③から④が出ないためです。**
③で分かるのは「英語に触れる1時間あたり、いくら払うか」だけ。
1時間あたりが安い候補が、上達が速い候補だとはかぎりません。

④を知りたい場合に見るのは、費用ではなく次のようなところです。
・1コマの中で、自分が話している時間がどれくらいあるか
・間違いを直してもらえる回数があるか
・授業のあとに復習する時間が取れる組み方か

これらは金額表には載らないので、学校ごとに個別に確かめることになります。
```

### 費用幅が割れる理由（H3「同じ『1ヶ月』でも、出てくる金額が3倍ちがう」）

```
提案：同じ「セブ島留学 1ヶ月」で調べても、
出てくる金額の幅は出典によってかなり違います。
下限が15万円台のものもあれば、40万円台から始まるものもあります
（2026年8月10日に検索して確認）。

3倍近く違うのは、どちらかが間違っているからではなく、
**含めている項目が違う**ためであることが多いです。

見るのはこの4つです。
・授業料だけか、滞在費まで含んでいるか
・渡航費（往復の航空券）が入っているか
・食費・光熱費・ビザ関連の現地費用が入っているか
・部屋のタイプ（1人部屋か相部屋か）はどれを前提にしているか

**金額を比べる前に、「その数字が何を含んでいるか」を先に見る。**
これが揃っていない表どうしを並べても、比べたことになりません。
```

> **この節では、特定の費用相場を断定していない。**
> 「15万円台のものもあれば、40万円台から始まるものもある」は
> **検索して見た範囲の観測**であって、相場の主張ではない。
> 確認日（2026年8月10日）を付けてある。

### 合わない人・注意点（H2「この出し方が向かない場合」）

```
提案：この記事の出し方（1時間あたりで並べる）が
合わない場合もあります。

・**期間が2週間より短い場合。** 渡航費の比重が大きくなって、
  1時間あたりが実態より高く出ます。同じ期間どうしでしか比べられません
・**金額より生活を優先したい場合。** 治安・食事・気候・時差は
  この計算に一切入りません。1時間あたりが最も安い候補が、
  自分にとって続けやすい候補とはかぎりません
・**まだ行き先の候補が1つも無い場合。** 表は候補を比べる道具なので、
  埋める相手がいないと使えません。先に条件（期間・予算の上限・
  仕事の扱い）を決めるほうが早いです
・**年齢や在学の条件で選べない行き先がある場合。**
  制度で外れるものを表に残すと、比較そのものがずれます

上の1つ目か2つ目に当てはまるなら、
この記事の表よりも、実際に行った人の生活面の記録のほうが役に立ちます。
```
