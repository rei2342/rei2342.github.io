# 検証ログ

型を変えたら、必ずここに1行残す。何を変えて、何が動いたかを後から追えるようにする。
表示数だけを見て良し悪しを言わない。**遷移率（記事に着地した数 ÷ 表示）で判断する。**

---

## 実験1: リンクの位置（2026-08-07）

| | |
|---|---|
| 投稿 | 2026-08-07 12:46 JST |
| 記事 | [546] オンライン英会話が3日で終わっていた私が、予約をやめて続いた90日 |
| URL | https://sakura-eigo.com/online-english-lessons-90-days-success/?utm_source=threads |

### 変えたこと（2点）

1. **リンクを3投稿目 → 2投稿目の末尾へ**（本命）
2. **フックを数字先頭の勝ち型へ**（「3日、4日、2日」で始める）

### 比較相手

| | 8/5の投稿 | 8/7の投稿 |
|---|---|---|
| リンクの位置 | 3投稿目（単独） | **2投稿目の末尾** |
| 1投稿目の入り | 「英語やらなきゃ と言い続けて27歳になった」 | **「3日、4日、2日」** |
| 表示 | 1334（38時間・まだ伸び中） | 測定中 |
| **遷移率** | **1.1%**（8/5〜8/6・ConoHaのログで11件） | 測定中 |

### 読み方

- **遷移率が1.1%を超えたら** → リンク位置が効いた。この型を固定して本数を稼ぐ
- **超えなかったら** → 原因は別。②の締め・記事タイトル・そもそも②に到達していない、の順で疑う
- **2点変えているので、どちらが効いたかは分けられない。** 表示が伸びればフック、
  遷移率が上がればリンク位置、と大まかに読む。両方動いたら次の1本でどちらかを戻す

### 補足

- 8/5の投稿は 719（13h）→ 780（14h）→ 883（18h）→ 1334（38h）と伸び続けた。
  **24時間では止まらない。48時間・7日で見る**
- GA4は8/6から計測開始。8/7の投稿が**GA4で正味の遷移率を測れる最初の1本**
- アイキャッチのファイル名が日本語でプレビュー画像が出ない問題があり、
  投稿前に31本すべて半角英数へ入れ替えた
