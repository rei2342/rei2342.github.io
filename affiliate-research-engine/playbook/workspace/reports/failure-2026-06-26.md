## アクションアイテム（次回実行に向けて）

GA4分析を実行するには、以下のいずれかの方法でCSVをエクスポートして配置する必要がある。

### GA4 CSVエクスポート手順

1. **GA4 管理画面** → 「レポート」→「エンゲージメント」→「ページとスクリーン」
2. 期間を **直近180日** に設定（90日前比較のため）
3. 右上の「↓ エクスポート」→「CSVとしてダウンロード」
4. 以下のパスに保存:
   ```
   affiliate-research-engine/playbook/workspace/reports/ga4-export-YYYY-MM-DD.csv
   ```

### 期待するCSVカラム構成

```
ページタイトル, ページパス, セッション数, ユーザー数, 表示回数, 直帰率, 平均エンゲージメント時間
```

または Google Search Console エクスポートの場合:

```
ページ, クリック数, 表示回数, CTR, 掲載順位
```
