## API復旧後に再実行する手順

### 1. 生成（WordPressへは送らない）

```
gh workflow run daily-article-drafter.yml
```

ゲートで止まれば `workspace/drafts/GATE.md` に該当文が出て、
**WordPressには送られない**（`sys.exit(0)` で終了）。
ゲートを通れば下書きとして投稿される。**その時点では公開しない。**

### 2. ゲートを手で通す

```
python affiliate-research-engine/playbook/scripts/draft_gate.py \
  affiliate-research-engine/playbook/workspace/drafts/<日付>.md
```

### 3. 目視監査（人がやる）

生成された本文を読んで、次を確認する。

- [ ] 台帳にない**体験**が書かれていないか（「試した」「受けた」「使った」）
- [ ] 台帳にない**金額**（貯金・支出・手取り）が書かれていないか
- [ ] 台帳にない**スコア**が書かれていないか
- [ ] **会話・第三者の台詞**が書かれていないか
- [ ] **職歴・渡航歴**が書かれていないか
- [ ] 「調べた」「候補に入れた」「公式情報を確認した」を使っていないか
- [ ] 公式の料金・仕様に**出典URLと確認日**が付いているか
- [ ] 仮定・試算に「例」「試算」の明記があるか
- [ ] 因果や学習効果を**出典なしで断定**していないか
- [ ] 他サービスを根拠なく下げていないか
- [ ] CTA直前に「どの条件に当てはまる人向けか」があるか
- [ ] **検索意図に本文が直接答えているか**（一番大事）

### 合格条件

| # | 条件 |
|---|---|
| 1 | `draft_gate` が **0件** |
| 2 | `cta_claim_gate` が **0件** |
| 3 | 上の目視チェック12項目がすべて ✅ |
| 4 | 本文に**読者が持ち帰れるもの**（計算式・確認手順・質問リストのいずれか）が1つ以上ある |
| 5 | 既存の改修済み記事と**同じチェックリストの使い回しになっていない** |

**1〜3が通らないうちは、WordPressの下書きを公開しない。**

### 不合格だった場合

ゲートを直すのではなく、**まず生成プロンプトを直す**。
ゲートは最後の砦であって、そこで止め続ける運用は生成が無駄になる。
プロンプトを直しても同じ型で落ちるなら、そのときはゲート側に型を追加する。

## ⚠️ 判明したゲートの限界

**`official_spec_without_source` は「URLと確認日が書いてあるか」しか見ていない。**
そのURLを実際に見たか、書かれた数字がそのページと一致するかは検証していない。

今回のドラフトは
「2026年8月8日時点の公式のプランページ(sptr.jp/plan)では、スパトレプランが月額5,980円、
ダブルプランが月額9,980円、教科書準拠プランが月額6,680円」
と書いてゲートを通過した。形式は正しいが、**この3つの金額が実際に一致するかは未検証**。

### 対応案（未実装）

`official_fact_check.py` の仕組みを流用して、
**記事に書かれた「URL＋金額」の組を実際に取りに行き、その金額がページに載っているかを照合する**
チェックを足す。TOEICの4件で使った方式をそのまま金額に適用できる。
