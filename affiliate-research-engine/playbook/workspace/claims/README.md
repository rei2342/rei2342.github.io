# 体験主張の確認工程

## このツールの位置づけ（2026-08-08に確定）

`claim_extractor.py` は**自動事実認定器ではない**。
**人が確認すべき主張の候補を漏れなく出すための抽出器**として扱う。

構造改修は2026-08-08の12周目で終了した。これ以上の精度追求はしない。
機械の判定（experience / modality / subject）は候補の絞り込みに使うだけで、
**そのまま事実として採用しない**。判断は必ず原文を読んだ人がする。

## ファイル

| ファイル | 中身 |
|---|---|
| `CLAIMS.csv` | 抽出した命題の全件。実行ごとに作り直す |
| `CLAIMS.md` | 読む用。層別サンプルと上位10件 |
| `EXCLUDED.md` | 抽出から外したブロック。**除外しすぎ**を確かめる用 |
| `AUDIT_DECISIONS.csv` | **人手の判定。ここだけが残る**。実行しても消えない |

⚠️ **`claim_id`（C011など）は実行ごとに変わる。** 出現記事数の順に振り直すため。
判定を記録するときは `post_ids` と `sentence_head` で照合する。
`AUDIT_DECISIONS.csv` の `claim_id_at_decision` は、判定した時点の値の控え。

## 判定の種類

| 値 | 意味 | 台帳へ |
|---|---|---|
| `verified` | 実体験だと確認できた | **転記する** |
| `partially_verified` | 一部が正しい | 正しい内容を確認してから登録 |
| `fictional` | 実体験ではない | **入れない** |
| `false_positive` | 抽出の誤り。主張自体が存在しない | **入れない** |
| `unknown` | まだ分からない | 入れない |
| `out_of_scope_service` | サービス利用ではない | `experience_facts.csv` 側の候補 |
| `pending_owner_check` | 運営者の確認待ち | — |

`false_positive` の判定は、**抽出器の一般ルールへは足さない**。
今回の監査上の人手判定として、この場所にだけ記録する。

## 確認する順番

1. **案件名を伴う利用体験**（留学情報館・スパトレ・speek・ネイティブキャンプ ほか）
2. **金額・期間・回数・スコアを伴う体験**（4万5000円・3ヶ月・600点 など）
3. **留学・渡航・職歴**
4. **英語学習の失敗・継続経験**
5. **数値のない一般的な一人称表現**

上から順に確定させる。1が一番危ない（未使用サービスの体験談になる）。

## 数字の扱い（2026-08-08に確定）

**確認済み台帳にない一人称の数字は、原則として公開記事から外す。**
681件を1件ずつ事実確認しない。種類ごとに変換ルールで処理する。

| 種類 | 台帳が unknown のとき |
|---|---|
| 個人スコア | 一人称の点数・推移を削除 |
| 個人支出 | 「払った」を削除。確認済みの公式料金か、明示した試算へ |
| 個人貯金 | 一人称の残高を削除 |
| 個人の期間・回数 | 未確認の体験としての数字を削除 |
| 公式料金 | 公式出典と確認日を付ける |
| 費用相場 | 根拠・対象範囲・基準日を確認する |
| 仮定・試算 | 「例」「試算」と明記して残す |
| 一般データ | 一次情報か信頼できる出典を付ける |

⚠️ **「さくらの正しいTOEICスコア」を新しく決めない。**
確認済みの実データが登録されるまで、さくら固有のスコア履歴を持たせない。
これが記事間の矛盾を止める唯一の方法になる。

生成側にも同じ制約を入れる。**入れないと次の記事でまた別の履歴が生まれる。**

## 今回の監査で外す保護

- **本文3,000字の下限（wp_audit の MIN_CHARS）は保護対象にしない**（2026-08-08）。
  未確認の表現を削って短くなっても、検索意図に十分答えられていれば問題としない。
  字数を守るために、確認できない体験を残すほうが害が大きい

## いま止めていること

- **記事の自動修正**。全体の確認が終わるまで開始しない
- **台帳への転記**。`verified` としたものだけを入れる。
  `partially_verified` は内容を確認してから、
  `fictional` と `false_positive` は入れない
- `experience.csv` は全件 `unknown` のまま。**記事から推測して埋めない**
