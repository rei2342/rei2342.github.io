## 9. バックアップとロールバックの方法

内部リンクを入れる前の本文を、記事ごとに保存してある。

| 場所 | 中身 |
|---|---|
| `workspace/backups/2026-08-09/links/<記事ID>.json` | **内部リンク反映前**の `content_raw`（49本すべて） |
| `workspace/backups/2026-08-09/hrefs/526.json` | リンク修復前の526 |
| `workspace/backups/2026-08-09/checklist/288.json` | 確認項目を分ける前の288 |
| `workspace/backups/2026-08-09/titles/<記事ID>.json` | タイトル差し替え前の6本 |
| `workspace/backups/2026-08-08/<記事ID>.json` | 前回の改修前 |

いずれも `{"id", "checked_at", "content_raw"}` の形。

### 戻し方

**内部リンクだけを外す場合**（本文の改修は残す）:
挿入したブロックは印で囲んである。

```
<!-- internal-links:START -->
<h2>…</h2><ul>…</ul>
<!-- internal-links:END -->
```

この印から印までを消せば、リンクだけが外れる。

**記事を丸ごと戻す場合**:

```bash
python - <<'PY'
import json, requests
pid = "273"                       # 戻したい記事
day = "2026-08-09"
raw = json.load(open(f"affiliate-research-engine/playbook/workspace/"
                     f"backups/{day}/links/{pid}.json"))["content_raw"]
requests.post(f"https://sakura-eigo.com/wp-json/wp/v2/posts/{pid}",
              auth=("rei.00pt2342@gmail.com", WP_APP_PASSWORD),
              json={"content": raw}, timeout=60)
PY
```

WordPress側のリビジョンからも戻せる（管理画面 → 記事 → リビジョン）。
