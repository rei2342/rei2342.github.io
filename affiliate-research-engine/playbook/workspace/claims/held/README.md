# 保留中の改修版（WordPressへ送らない）

品質再監査で、**文単位の差し替えでは足りない**ことが分かった25本。

## 何が起きたか

2026-08-09に「31本の旧設定を0件にした」と報告したが、これは正しくない。

`27歳`・`営業事務`・`5年後回し` のような**語**は消えたが、
その周りに残っていた**一人称の語り**をそのままにしていた。

    「私はソファに沈み込んでいた」
    「手帳を開くと、私の言い分がぐらついた」
    「スクールに通っていた頃を思い出す」

ゲートの13分類は事実の「種類」を名指しで拾う形だったので、
種類に当てはまらない地の語りが素通りしていた。
結果として、読者向けに直した文と一人称の語りが同じ記事に混ざった。

台帳が空である以上、これらは**未確認の体験**にあたる。

## いま止まっている理由

`quality_rules` に「未確認の一人称の語り」を追加した。
この25本は全部そこで止まる（合計362件）。
`rewrites/` に置いたままだと `draft_gate` が全体を落として、
改修済みの記事まで反映できなくなるので、ここへ移した。

## 次にやること

**文単位の差し替えではなく、全文の再構成**が要る。
全文を書き直した6本（292 289 42 546 238 294）は
同じルールで0件になっているので、書き方の基準はそちらに揃える。

  - 読者が今困っていること
  - どこで判断に迷うか
  - 今日確認できること
  - 続けられる条件

新しい年齢・職歴・期間は作らない。

## 公開中の記事はどうなっているか

**公開は止めていない。** 旧設定の語はすでに消えているので、
以前より悪い状態ではない。残っているのは一人称の語りで、
これは全文の再構成で外す。
