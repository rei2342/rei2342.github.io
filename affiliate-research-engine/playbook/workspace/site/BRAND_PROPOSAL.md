## 2. トップページの構成案

現状：新着記事の一覧だけ。初訪問者は「誰向けか」「何が分かるか」「何から読むか」を判断できない。

### 判断できる状態にする6つの要素

```
┌─────────────────────────────────────┐
│ ① このサイトは誰向けか（1行）              │
│   働きながら英語をやり直したい大人へ         │
├─────────────────────────────────────┤
│ ② 何が分かるか（3つ）                     │
│   ・自分に合う勉強法の選び方                │
│   ・サービスの比べ方（料金だけで選ばない）     │
│   ・留学・ワーホリの費用の出し方             │
├─────────────────────────────────────┤
│ ③ 何から読めばいいか（悩み別の入口4つ）       │
│   □ 続かない → 勉強法                    │
│   □ 点が止まった → TOEIC                 │
│   □ サービスを選べない → 比較              │
│   □ 海外を考えている → 留学・ワーホリ        │
├─────────────────────────────────────┤
│ ④ 4つのクラスターへの導線                  │
│   勉強法 / サービス比較 / AI英語学習 / 留学   │
├─────────────────────────────────────┤
│ ⑤ 事実確認と記事の書き方の方針（1ブロック）    │
│   公式情報には出典と確認日を付ける            │
│   確認できない体験は書かない                 │
│   効果を保証しない                         │
├─────────────────────────────────────┤
│ ⑥ PRを含むことの明示                      │
└─────────────────────────────────────┘
```

⑤は他サイトがまず書かない部分で、**今回の監査で作った運用そのものが差別化になる**。
「体験談を書かない代わりに、判断材料と出典を出す」という立ち位置を先に宣言する。

### ③の入口に置く記事（改修済みのものだけ）

| 悩み | 入口記事 |
|---|---|
| 続かない・アプリで足りるか | 310 無料・低価格の英語アプリで足りる人と、足りない人の分かれ目 |
| TOEICが止まった | 304 TOEIC 600点で止まっているとき、勉強法を変える前に確認する4つのこと |
| 500点台から上げたい | 32 TOEIC500点から上げる勉強法｜最初に確認したい4つのこと |
| 留学・ワーホリの費用 | 272 フィリピン留学の費用を社会人が計算する方法 |

## 3. カテゴリの再設計案

現状：ほぼ未分類。検索者の悩みとも収益導線とも対応していない。

| 新カテゴリ | 中身 | 主な収益導線 |
|---|---|---|
| **勉強法・続け方** | 続かない／習慣／独学の限界 | スパトレ・スタサプ |
| **TOEIC・スコア** | 停滞／内訳の分解／リスニング | speek・スパトレ |
| **サービスの選び方** | アプリ比較／コーチング／オンライン英会話 | ネイティブキャンプ・DMM・レアジョブ |
| **AI英語学習** | AI翻訳／ChatGPT／AI英会話／文字起こし | speek・Notta（work_english のみ） |
| **留学・ワーホリ** | 費用／エージェント／国別／制度 | ネイティブキャンプ留学・留学情報館・フィリピン留学ナビ |

**移行時の注意**：カテゴリのslugを変えると既存URLが変わる可能性がある。
**新規カテゴリを作って記事を移す**形にして、旧カテゴリは残す。削除しない。
