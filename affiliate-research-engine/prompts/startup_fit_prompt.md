## 評価A：startup_fit（各0〜100で採点）

### 1. zero_follower_viable（フォロワー0でも成立するか）
- 拡散力・フォロワー数に依存せず、コンテンツ単体で価値を提供できるか
- 検索流入・ハッシュタグ流入でも読まれる内容か
- フォロワーゼロ期の「信用なし状態」でもCVが見込めるか

### 2. no_track_record_needed（実績提示が不要か）
- 「〇ヶ月で〇円稼いだ」などの成果報告なしでも売れるか
- 体験談・レビューベースで実績不要の訴求が成立するか
- 商品の特性上、推薦者の実績が問われにくいか

### 3. no_face_required（顔出し不要か）
- 匿名アカウント・テキストのみでも売れるか
- ビジュアルコンテンツへの依存度が低いか
- 顔出しがないことで信頼性が大きく落ちないか

### 4. no_physical_product_needed（実機・実物不要か）
- デジタル・無形サービスで物理的な商品確認が不要か
- 実機購入・実体験なしでもコンテンツが作れるか
- スクリーンショット・操作動画・公式情報だけで訴求できるか

### 5. free_trial_available（無料体験で検証できるか）
- 自分自身が無料で試せるか
- 無料体験→体験談という流れで自然にコンテンツが作れるか
- 費用ゼロでコンテンツを作り始められるか

### 6. trust_free_conversion（信頼構築前でも購買につながるか）
- 初回接触で購買意欲が高まるほど訴求の即効性があるか
- フォロー・信頼関係なしでも「今すぐ欲しい」と感じさせられるか
- 緊急性・損失回避・即効性の訴求が有効に機能するか

## 評価B：zero_cost_validation_score（各0〜20で採点）

新規SNSアカウントが「費用ゼロで案件を検証できるか」を評価します。
これは startup_fit のサブスコアで、新規参入時の最重要指標です。

### 1. free_signup（無料登録可能か）
- サービス・会員登録が無料でできるか
- 0点: 有料登録のみ / 10点: 無料プランあり（機能制限） / 20点: 完全無料で登録・利用開始できる

### 2. free_trial（無料体験可能か）
- 試用期間・無料体験プランが存在し、体験談コンテンツが作れるか
- 0点: 無料体験なし / 10点: 限定的な無料体験あり / 20点: 十分な無料体験あり（コンテンツが作れる）

### 3. self_application_ok（本人申込可能か）
- 規約上「本人申込NG」でなく、自分で申し込み・購入して体験できるか
- セルフバック可能ならさらに評価が高い（実質コスト削減）
- 0点: 本人申込NG明示 / 10点: 本人申込可だがセルフバック不可 / 20点: 本人申込可かつセルフバックOK

### 4. no_purchase_needed（購入・実機不要か）
- 物理商品の購入や実機なしにコンテンツが作れるか
- 公式情報・デモ動画・スクリーンショットのみで訴求できるか
- 0点: 実機購入が事実上必須 / 10点: 購入なしでも代替コンテンツが作れる / 20点: 購入完全不要

### 5. no_face_needed（顔出し不要か）
- 顔出しなしでテキスト・スクリーンショットのみで信頼性ある訴求が成立するか
- 0点: 顔出し必須カテゴリ / 10点: 顔出しがあった方が有利 / 20点: 完全匿名・テキストのみで成立

### 6. no_track_record_needed（実績不要か）
- 「〇kg痩せた」「〇万円稼いだ」などの成果実績の提示なしで訴求できるか
- 0点: 実績提示が事実上必須 / 10点: 実績あれば有利だが不要でも成立 / 20点: 実績完全不要の訴求が自然に成立

total = 6軸の合計（最大120点）

## レベル判定基準（startup_fit score）
- **High（70以上）**: フォロワー0・実績ゼロでも今週から検証開始できる
- **Medium（45〜69）**: 一定の準備や条件があれば検証できる
- **Low（44以下）**: 実績・実機・顔出しなど障壁が高く新規参入には不向き

startup_fit.scoreはbreakdownの6軸の平均値（整数）にしてください。
startup_fit.levelはscoreに基づいて自動判定してください（70以上=High, 45-69=Medium, 44以下=Low）。
zero_cost_validation_score.totalは6軸の合計値（最大120）にしてください。

## 評価C：Content Engine Fit（CEF）（各0〜20で採点）

このジャンル・商品カテゴリを使って「SNSアカウントを長期育成・資産化できるか」を評価します。

### 1. ネタ量産性（content_producibility）
- 同一ブランド・ジャンルでコンテンツを繰り返し量産できるか
- 0点: 1〜2本のみ / 10点: 10〜20本程度 / 20点: 50本以上継続量産可能

### 2. 市場規模（market_size）
- ターゲットとなる潜在視聴者・検索ユーザーの市場規模
- 0点: ニッチ（数万人） / 10点: 中規模（数十万人） / 20点: 大規模（数百万人以上）

### 3. 継続性（continuity）
- 1〜2年後も継続してコンテンツを投稿できるか（季節・トレンド依存度）
- 0点: トレンド依存で短命 / 10点: 1年程度継続可能 / 20点: 長期的に安定した需要がある

### 4. 横展開性（cross_expansion）
- 関連テーマ・商品ジャンルへの横展開でコンテンツ幅を広げられるか
- 0点: 単品のみ / 10点: 数商品への展開可能 / 20点: カテゴリ全体・関連ジャンルへ無限展開可能

### 5. SNSショート動画適性（short_video_fit）
- TikTok/Instagram Reels/YouTubeショートでのバズりやすさ
- 0点: 動画不向き / 10点: ある程度動画映えする / 20点: ギミック・before-after・比較動画に最適

### 6. アカウント資産化しやすさ（account_asset_potential）
- このジャンルで継続するとフォロワー獲得・権威形成・長期資産化がしやすいか
- 0点: アカウント価値が形成されにくい / 10点: ある程度の資産化可能 / 20点: ジャンル特化で長期的権威形成・高収益化しやすい

cef.total = 6軸の合計（最大120点）
cef.score = round(total / 1.2)（0〜100に換算）
