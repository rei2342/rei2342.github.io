## 評価：creator_fit（各0〜100で採点）

### 【発信できるか】（6軸）

### 1. first_hand_info（一次情報保有度）
- 発信者がこの案件ジャンルについて、実体験・実データ・実績を持っているか
- 0点: 全く経験なし、完全な外部者 / 50点: 間接的な経験や知識はある / 100点: 今まさにリアルタイムの一次データを生成している

### 2. expertise_alignment（専門性適合）
- 発信者の専門知識・スキル・実績が、この案件を語る上で活きるか
- 0点: 専門性が全く活かせない / 50点: 周辺知識として活かせる / 100点: 発信者の専門性がそのまま強みになる

### 3. content_sustainability（継続ネタ量）
- 発信者自身の経験・知識から、6ヶ月以上コンテンツを量産し続けられるか
- 0点: 1〜2投稿で話が尽きる / 50点: 2〜3ヶ月は続くが枯渇しそう / 100点: 新しいネタが自動的に生まれ続ける構造がある

### 4. differentiation_potential（差別化可能性）
- 発信者がこの案件で、他の誰も作れないコンテンツを生み出せるか
- 0点: 誰でも書けるテンプレ内容しか出せない / 50点: 少し独自の視点が加えられる / 100点: この発信者にしか語れない圧倒的に独自のコンテンツが作れる

### 5. authentic_voice（体験語りの自然さ）
- 発信者が一人称で語ったとき、フォロワーに「本物の体験談」として信頼されるか
- 0点: 明らかに経験していない・嘘っぽく見える / 50点: 工夫すれば自然に見せられる / 100点: 語るだけで「この人が言うなら信頼できる」と感じられる

### 6. longevity（発信継続性）
- この案件ジャンルで、モチベーションを維持しながら1年以上発信し続けられるか
- 0点: 1〜2週間で発信意欲が枯渇する / 50点: 3〜6ヶ月は続くが継続が難しい / 100点: 発信者の日常や成長と直結しており自然に継続できる

---

### 【発信し続けられるか・勝てるか】（4軸）

### 7. curiosity_fit（テーマ好奇心・飽きなさ）
- 発信者がこの案件ジャンルを「もっと知りたい・試したい・深めたい」と半年〜1年後も思い続けられるか
- Creator × Case domain の交差評価。同じ発信者でもジャンルにより大きく変わる
- 0点: 今週中に飽きる / 50点: 3〜6ヶ月は続くが義務感になる / 100点: 調べれば調べるほど面白くなり自然に発信が増える

### 8. authority_fit（テーマ権威性の積み上げやすさ）
- この案件ジャンルで発信を続けた時、「この人が言うなら信頼できる」という権威が積み上がりやすいか
- 注意：現時点の権威の有無ではなく、「このジャンルは権威が積み上がりやすい構造か」を評価する
- 0点: 誰が何を言っても信頼されにくいジャンル / 50点: 実績が積めば徐々に信頼される / 100点: 発信量×継続で急速に権威化しやすいジャンル

### 9. moat_fit（参入障壁の形成しやすさ）
- 発信者がこのジャンルで独自データ・独自体験・独自視点を積み上げた時に、他者が真似しにくい「堀」が生まれやすいか
- 注意：現時点での堀の有無ではなく、「このジャンル×この発信者の組み合わせで堀が形成されやすいか」を評価する
- 0点: 誰でも同じコンテンツが作れる（差別化不可能） / 50点: 継続すれば少し差別化できる / 100点: 発信者の専門性×ジャンルの構造上、他者が追いつけない状態になりやすい

### 10. leverage_fit（コンテンツ複利率）
- この案件を起点に、関連コンテンツ・関連媒体・関連案件・関連テーマが自然に増殖するか
- 「1投稿が100投稿に増殖する」構造か、「1投稿して終わり」の構造か
- 0点: そのレビュー1本で完結、次のネタが生まれない / 50点: 少し関連展開できる / 100点: 案件を起点に無限に関連コンテンツ・収益源が派生する複利構造

---

creator_fit.score = 10軸の平均値（整数、0〜100）
