## 2. プロフィール文候補 5個

**A：一文インパクト型（最短・最強）**
```
転職したいと思っていた。同時に、したくないとも思っていた。
その3年間の話と、その後を書いています。
```

**B：日常描写型（共感入口）**
```
日曜の夜だけ転職サイトを開いて、月曜には何もなかったことにする人間でした。
3年くらいそれをやって、ようやく少し整理がついた。
その記録を残しています。
```

**C：ストーリー型（信頼構築）**
```
入社3年目から転職を考えはじめて、「今じゃない」を3年繰り返した。
結局どうしたのか、何が変わったのか、ここに書いています。
同じように迷っている人のヒントになれば。
```

**D：等身大シンプル型**
```
会社員です。転職とキャリアのことをずっと考えていて、
ここはその思考の記録場所。答えより、考えた過程の方が大事だと思っています。
```

**E：感情最優先型**
```
転職したいのか、したくないのか、ずっと分からなかった。
それが3年続いた。同じような人に読んでほしいことを書いています。
```

**推薦：A + C を組み合わせた構成**
```
転職したいと思っていた。同時に、したくないとも思っていた。
入社3年目から「今じゃない」を3年繰り返して、ようやく少し整理がついた。
その記録を残しています。転職・キャリアを迷っている20代会社員に向けて。
```

## 4. 記事1本目（今回の記事）の公開情報

### タイトル
```
転職したいとも、したくないとも思っていた。それが3年続いた。
```

### note用 冒頭テキスト（記事本文の前に置く前置き）
サムネイル下に表示される文として機能。記事本文の冒頭はそのまま使えるが、
「なぜこれを書いたか」を一言添えると初見の読者が入りやすくなる。

```
転職の話、というより、「決められなかった3年間」の話です。

転職したいのか、したくないのか。
どちらとも言えないまま、「今じゃない」を繰り返して3年が経った。
同じような経験がある人に読んでほしい。
```

### 記事末尾の自然導線（「今、思うこと」セクションの後に追加）
```
---

ひとつだけ言えることがある。

求人を見る前に、自分の条件を先に整理すること。
転職する気がなくても、無料のキャリア診断や転職エージェントへの相談で、
「自分が何を大切にしているか」が思っていたより早く言語化できる。

3年迷ってから気づいたのは、転職するかどうかより先にその整理が必要だったということだった。
```

### プロフィールへの誘導文（記事末尾 * の後ろに追加）
```
転職・キャリアについて、同じような経験や気づきを書いています。
よければプロフィールも見てみてください。
```

## 6. noteに最初に置くべき記事テーマ 5本

| 順番 | タイトル案 | パターン | 想定読者 | アフィリエイト接続 |
|------|-----------|---------|---------|------------------|
| 1本目 | 転職したいとも、したくないとも思っていた。それが3年続いた。（今回） | 目的乖離型 | 転職迷走中 全員 | キャリア診断・無料相談 |
| 2本目 | 転職より先にやるべきだったこと。3年後に気づいた話。 | 前提崩壊型 | 転職活動開始前の人 | 自己分析ツール・エージェント |
| 3本目 | 会社が嫌いじゃないのに、月曜が嫌。この感覚の正体。 | 小変化大発見型 | 違和感期の人 | キャリア相談・診断 |
| 4本目 | 転職しなかった年の話。「今じゃない」と決めた理由。 | 反転型 | 転職しない派・現職改善中 | スキル系・副業系との接続も可 |
| 5本目 | 会社を変えても、同じ不満が出てきた。3社目でようやく分かったこと。 | 前提崩壊型 | 転職経験済みで再迷走中 | 自己理解・キャリア相談 |

### 設計意図

```
1本目 → 転職迷子の感情ど真ん中

3本目 → 違和感期の読者を広く拾う
4本目 → 転職しない読者への間口
5本目 → 転職経験済みの読者まで拾う

5本揃えた時点で：
「転職を迷っているあらゆる状態の読者に刺さるアカウント」が完成する。
```
