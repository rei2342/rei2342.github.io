## 2. 冒頭前書き 3パターン

note記事本文の前、タイトル直下に置くひと言。
読者が「どういう記事か」を0.5秒で判断するための案内文。

---

### A：フレーム型（最短）

```
転職の話というより、「決められなかった3年間」の話です。
```

---

### B：読者指定型

```
日曜の夜に転職サイトを開いて、月曜には何もなかったことにする。
そういう経験がある人に読んでほしい記事です。
```

---

### C：体験開示型

```
3年間、転職するかどうかを決められなかった。
なぜ決められなかったのかが分かったのは、3年後だった。
その話を書きました。
```

---

## 3. 末尾導線 3パターン

記事の「今、思うこと」セクションのあと、本文最終行として挿入。
アフィリエイト感ゼロ、直接売り込まない、でも接続できる余白を残す。

---

### A：個人体験型（最も自然）

```
あのころの自分に、ひとつだけ言えることがあるとしたら。

転職サイトを開く前に、「自分が何を大切にしているか」を先に言葉にしてみること。

無料のキャリア相談や診断ツールは、そのために使えた。
転職する気があっても、なくても。
話すことで、頭の中に散らばっていたものが少し整理された。

それだけで、「今じゃない」の繰り返しは少し短くなったと思う。
```

---

### B：気づき共有型

```
転職するかどうかより先に、「何を変えたいのか」を言葉にすることが必要だった。

無料の診断や初回のキャリア相談は、そのために使える。
転職する気がなくても入れる、というのは後から知った。

求人を眺める時間の一部を、自分を整理する時間に使っていたら、
3年は少し短かったかもしれない。
```

---

### C：静かな着地型（最もシンプル）

```
転職するかどうかを決める前に、
まず自分が何に疲れていて、何を変えたいのかを言葉にする必要があった。

求人を眺める前に、無料の診断やキャリア相談で一度整理しておけば、
同じ場所で3年も迷わなかったかもしれない。
```

---

推薦：**A**（個人体験として読まれるため最も信頼を損なわない）

### 設計の流れ

```
1本目：転職を迷っている感情のど真ん中に置く
        ↓
2本目：「なぜ決められないのか」の答えを渡す
        ↓
3本目：転職を考えていない層にも間口を開く
        ↓
4本目：「転職しない」という選択にも寄り添う
        ↓
5本目：転職経験済みで再迷走している層を拾う
```

**5本公開後のアカウントの状態：**
転職の迷い始め・迷走中・経験済み再迷走、の全状態に対応している。
どの状態から来ても「自分のことが書いてある」と感じられるアカウントになっている。
