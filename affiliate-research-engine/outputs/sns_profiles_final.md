## 7. プロフィール採用推薦

---

### Instagram → 案A（ナラティブ型）を推薦

```
「今じゃない」を3年繰り返した会社員。

転職するかどうかより先に
決めることがあった、という話を
このアカウントに書いています。

深掘りはnoteで。
```

**理由：**
「今じゃない」という言葉が記事タイトルとSNS投稿と一致するため、プロフィールから記事への一貫性が生まれる。
「転職するかどうかより先に決めることがあった」という一文が読者の知的好奇心を刺激する。
「深掘りはnoteで」が自然なnote誘導として機能し、広告感がない。
150文字以内に収まり、視認性が良い。

---

### TikTok → 案B（一言型）を推薦

```
「今じゃない」を3年言ってた会社員。
転職・キャリアの話をしています。
```

**理由：**
TikTokは0.3秒で離脱するかを判断するプラットフォーム。
一行目「「今じゃない」を3年言ってた」が具体性と共感を同時に作る。
2行で「誰が」「何を話すか」が完結している。
余計な説明がなく、軽い。

---

### Threads → 案A（二段落型）を推薦

```
転職したいのか、したくないのか。
3年間、分からなかった。

ようやく整理がついたことを書いています。
長い話はnoteで。
```

**理由：**
Threadsは短くても文章として読まれるプラットフォーム。
一段落目でアカウントの核となる感情を置き、二段落目で「今どういう状態か」と「noteへの誘導」を入れるのが最も自然。
「長い話はnoteで」が機械的にならず、日常語として機能する。

---

### note → 案①（確定版・STANDARD）を推薦

```
転職したいと思っていた。
同時に、したくないとも思っていた。

入社3年目から「今じゃない」を繰り返して、
ようやく少し整理がついたので、
その記録を残しています。

転職・キャリアを迷っている20代OLに向けて。
```

**理由：**
すでに確定済み。一行目の矛盾提示がnoteで最も読まれる記事1本目と直結している。
「記録を残しています」というトーンが売り込みでも解説でもなく、日記的な信頼感を作る。
最終行「転職・キャリアを迷っている20代OLに向けて」で読者を明確に指名しており、Instagramやリール経由で来た読者が「自分向けだ」と感じやすい。

---

### 全体一貫性まとめ

```
TikTok  → 「今じゃない」を3年言ってた（一行）
Instagram → 「今じゃない」を3年繰り返した会社員（冒頭）
Threads → 転職したいのか、したくないのか（感情）
note    → 転職したいと思っていた。同時に、したくないとも（矛盾）

どのプラットフォームから来ても
「この人、自分と同じことを考えてた」
と感じられる設計になっている。
```
